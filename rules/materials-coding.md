# Materials Coding

**Rule: no address, no purchase.**

Every material dollar codes to a property, not to "supplies."

## The coding standard

| Field | Example |
|---|---|
| Property | 820 28th St |
| Date | 2026-09-16 |
| Vendor | Home Depot |
| Amount | $412.18 |
| Category | Lumber |
| Receipt | photo attached, same day |
| Who bought it | Cesar |

Anything that cannot be coded to an address is a leak. It gets logged as a leak,
not filed as "supplies."

## Enforcement

- Company card purchases without an address in the memo get declined going forward.
- Cherry maps the trailing 14 days to addresses. Whatever will not map is the
  baseline leak number. That number is the reason for the rule.
- Amazon materials buys code the same way as Home Depot. "It was Amazon" is not a
  category.

## Why

Two reasons, both money:

1. You cannot tell whether a rehab worked if you do not know what it cost.
2. Materials that walk off a job are invisible until purchases are tied to a
   property and a person. Tied purchases make the pattern obvious in a month.
