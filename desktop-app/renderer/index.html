Google won't let any app touch your spreadsheets unless it's registered to a Google Cloud project of yours. Five minutes, once:
  1. console.cloud.google.com → create or pick a project
  2. APIs & Services → Library → enable Google Sheets API
  3. OAuth consent screen → External → add your own Gmail under Test users
  4. Credentials → Create credentials → OAuth client ID → Desktop app
