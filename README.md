# MLS-Full-Access

Twin Home Buyer tools.

- [`dealtrack/`](dealtrack/README.md): **DealTrack**, a read-only Google Ads dashboard for the Twin Home Buyer account: spend, conversions, wasted search terms with suggested negative keywords, spend by city, day and hour, and conversion setup.
- `landing-page-copy.csv`: headlines and body copy for the 13 ad groups, recovered from the Bateman campaign's change history, for rebuilding the landing page.
